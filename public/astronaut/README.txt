Cosmic Astronaut Sprite Pack

10 transparent PNG sprites on 480x360 RGBA canvases.
The original generated sprite sheet is included as a reference.

These are visual poses, not true 3D geometry. Sprite dimensions are consistent, but their character pivots vary because some poses contain exhaust/trails. In the website, use a stable image wrapper and blend/transition the individual frames.
